# ai-call-audit

Бот аудиту телефонних дзвінків. Завантажує аудіо й таблицю з Google Drive,
транскрибує (Gemini API), аналізує якість роботи менеджера (Gemini), заповнює
оцінкову таблицю та вивантажує результати назад на Drive.

## Що робить

1. Завантажує аудіофайли з вихідної папки Drive у `work_files/`.
2. Транскрибує кожен файл через Gemini API; `.txt` транскрипт кладе поруч з
   аудіо в `work_files/`.
3. Експортує таблицю-шаблон з Drive у локальний `.xlsx`.
4. Для кожного дзвінка через Gemini визначає: тип робіт (зі списку), дату
   запису на сервіс, оцінку менеджера, бали 1/0 за критеріями та коментар.
5. Негативні коментарі (дзвінок НЕ ОК) заливає червоним.
6. Додає колонку «Бали» — суму оцінок 1/0.
7. Вивантажує транскрипти у вихідну папку аудіо, а звіт
   «Звіт прослуханих розмов.xlsx» — у папку `REPORT_FOLDER_ID`.

## Налаштування

1. Встановіть залежності:
   ```
   pip install -r requirements.txt
   ```
2. У Google Cloud Console увімкніть **Google Drive API**, створіть
   **OAuth Client ID** типу **Desktop app**, завантажте його JSON у
   `credentials/oauth_client.json`.
3. Скопіюйте `.env.example` у `.env` та заповніть:
   - `SOURCE_FOLDER_ID`, `SOURCE_SHEET_ID`, `REPORT_FOLDER_ID` — ID з URL Drive;
   - `GEMINI_API_KEY`, `GEMINI_MODEL` — транскрипція аудіо та аналіз дзвінків;
   - `MAX_FILES` — обмеження для тесту (0 = усі файли).
4. Перший запуск відкриє браузер для входу Google — токен збережеться у
   `credentials/token.json`, наступні запуски проходять без входу.

## Запуск

```
python main.py
```

Для першого тесту виставте `MAX_FILES=1` або `2`.

## Структура

| Файл | Призначення |
|------|-------------|
| `config.py` | Налаштування з `.env` |
| `google_client.py` | OAuth-авторизація + Drive API (читання й вивантаження) |
| `transcribe.py` | Транскрипція через Gemini API |
| `analyze.py` | Аналіз дзвінка через Gemini |
| `main.py` | Оркестрація пайплайну |

## Примітки

- Рядок-шапка таблиці визначається автоматично (за збігами ключових слів).
- Тип і варіанти колонок беруться з випадаючих списків таблиці (data
  validations): критерії 1/0, «Яка робота з топ 100», «Результат»,
  «Запчастини». Якщо списків немає — тип класифікує модель Gemini за назвами.
- Випадаючі списки автоматично поширюються на нові рядки — тип робіт та інші
  поля лишаються вибором з меню в Excel.
- Дата й номер телефону беруться з імені аудіофайлу
  (`РРРР-ММ-ДД_..._<номер>_...`).
- Колонка «Бали» додається праворуч; нові рядки дописуються в кінець таблиці.
- Повторний запуск пропускає вже скопійовані аудіо та наявні транскрипти.
